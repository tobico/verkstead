# design-fixes

A batch of settled design improvements to the workbench: the waiting-on-you
marks stop crying wolf (manual stops and closed conversations no longer carry
them), a Done conversation announces itself with a dot and a header label, task
completion moves to the `TODO.md` checkbox as its source of truth, task and
stage cards window to five items, the pull request card becomes clickable and
grows check status, unknown transcript lines fold into bookkeeping, and a run
of smaller chrome fixes land alongside: transcript autoscroll, the drag-drop
stuck state, the shared commit-message card, and the menus.

Each task is a vertical slice settled by the grilling on this Conversation; the
order is the dependency.
