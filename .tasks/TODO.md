# The interview, one session and the wrap-up across

Three more built-in Activities cross the boundary stage 08 drew, and with them
every session a Develop, Review or Fix Merge Issues Conversation runs is
launched by a component: the **interview** (the grilling session, ending in the
Direction picked on its closing Set), **one session** (an inline build, a
`submitting` step or an `instruction` steer under a skill with the Done-signal
evidence it expects), and the **wrap-up** (one Activity with declared watchers
over the pull request — checks, comments, the review, mergeability — that opens
the pull request where none stands and ends when it is merged, closed or given
up on). Investigating rounds are wired as a configuration of stage 08's
follow-up rounds.

The suite passes against the components unchanged, the Plugins page lists the
three under Built-in, and nothing on the workbench has moved. Stage 08's world
held only `launch`, `wait`, `git-facts`, `notice` and `stop`, so this stage
also grows it with what the wrap-up needs (Set 1838).
