# Dependencies on the record

A roadmap's stage lines carry what each stage stands on and, where it has one,
the platform it wants — `after 02, 03`, `no dependencies`, `on windows` — and
Verkstead reads them. The reading is shown on the roadmap's details pane, a
roadmap that declares badly is refused at the roadmap session's `verkstead
done`, and the three skills that write the end of a stage line all leave the
declaration where it is.

**Nothing schedules by any of it yet.** Every roadmap still runs in order, and
a roadmap written before this — which is every roadmap so far — declares
nothing and is read exactly as it was. What this stage puts on the record is
what stage 04's scheduler will read.
