# UI refinements

A batch of workbench refinements settled by grilling: four fixes (a dropped
conversation switch, the page growing under the panes, an all-caps terminal,
a slow first diff), a quieter setup pane (branch autosave, a base-commit
dropdown, an always-drawn grilling button), per-repo memory of the last-used
agent profiles, shared menu and modal components with the settings page moved
onto them, and timeline presentation put straight.
