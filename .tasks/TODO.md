# Workbench

Turns this askance checkout into Verkstead by name, and gives it the records a
grilling session will need: watched paths as a security boundary, repos
registered from inside them, conversations that carry a brief and a branch
name, and agent profiles to run under. Nothing executes yet — the *start
grilling* button and everything behind it is the next stage.

The phone answering flow keeps working after every task here. The workbench
takes `/` and the pending list moves to `/pending`; that route and `/archive`
are transitional, and retire in the next stage once question sets are reached
through their conversation.
