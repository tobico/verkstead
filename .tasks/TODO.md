# Refinement

The daily-driver polish that was deliberately deferred, plus the two things the
first real running turned up. Verkstead now drives this repository's own work —
it executes this roadmap — and what running it against a machine it was not
written against exposed is that a session's CLI is not the server's build, and
that one stored Question Set the server can no longer read takes its whole
Conversation down with it. Those come first, because they are what the instance
is broken by today.

Then the five the brief named: deferred asks that never block a session,
pausing when a claude account exhausts its window, milestone notifications
alongside the needs-you set that already fires, a sidebar ordered by hand with
markers on what wants attention, and reopening a finished Conversation with a
new brief round.
