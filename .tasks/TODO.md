# Workbench refit

A sweep of settled UI changes across the workbench: setup moves out of the
details pane onto the brief card, profiles carry lists of models and every
choice becomes a profile-and-model pairing, the timeline's cards take on new
shapes (clamped markdown, interview-style question sets, checkbox task lists,
a pinned carousel, interruptions answered like a sheet), the panes become
resizable with a capped and centered detail column, the contents sidebar
returns to diffs, transcript command pairs merge into cards, and the
new-conversation form becomes a dropdown menu.

Each task is a vertical slice a session builds alone; the order is the
dependency.
