# roadmap-adoption

**Adoption** is how a roadmap that already exists in a registered Repo — written
by the old tools, by hand, or by anything that was not this Verkstead — enters
the unattended pipeline without a grilling. Today a roadmap enters only by being
*written*: what starts a stage is a Conversation's branch having touched
`docs/roadmaps/`, and an already-committed roadmap was touched by no branch
Verkstead knows. Adoption is the missing entry point, and the human's press
stands in for the settling predecessor that would otherwise have started the
stage.

Once one stage runs as a Conversation the chain continues unattended for free —
that stage's own plan commit touches the roadmap, so the existing carry-on path
picks it up with nothing changed. The surface is a notice in the conversations
list naming the Repos that hold **Abandoned** roadmaps; clicking one creates an
adopting Conversation in Draft, whose page takes the two Profiles and a base
commit override and adopts on one press.
