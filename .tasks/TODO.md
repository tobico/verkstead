# relax-fix-merge-pr-limit

A **Review** or a **Fix Merge Issues** cannot be pointed at anything Verkstead
built: the take-up refuses a pull request another Conversation has on its
record — *"That pull request is already another conversation's, and there is one
conversation per piece of work"* — and every pull request Verkstead opens is
some Conversation's from the moment it is opened. In a stack of stages that is
every link.

The rule becomes **one open Conversation per pull request**, open being neither
Done nor Closed. A Done holder is Closed to make way, a holder still at work
refuses as before, and a close that would discard uncommitted changes is asked
about first. The decision and what was rejected are in
[ADR-0020](../docs/adr/0020-a-conversation-has-a-process.md), *One open
Conversation per pull request*.
