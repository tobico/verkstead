# Tasks placed by platform

A task that wants an operating system runs on it. A line in `.tasks/TODO.md`
carries `on linux`, `on macos` or `on windows` after its link, read by the same
`declarations::read` a stage line is, and a word that is not one of the three
is refused at the `verkstead done` of the session that wrote the backlog.
Before launching a declared task, the driver moves the Conversation by the
ordinary Transfer to the first permitted device of that platform that answers
cleanly, and the far end's Resume launches the task there; an inline run whose
proposal wants exactly one platform starts there the same way. The work stays
wherever the last move left it.

Where no device of the platform can take it, this stage writes a Notice and
runs the task where it is — stage 04 turns the askable cases into a Question
Set of Verkstead's own. Demonstrable: a backlog with one Windows task, worked
on Linux with a Windows device ticked, moves for that task, works it there, and
the next undeclared task runs where the work now is.
