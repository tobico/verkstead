# Stages placed by platform

A stage line's `on windows` places the stage. A roadmap's stages inherit the
roadmap Conversation's *May be transferred to* ticks. A declared stage is made
on its home device, as every stage is, and moved by the ordinary **Transfer**
to the first reachable permitted device of its platform before its first
session starts. Where none is reachable, or none is ticked, stage 04's Set asks;
where no device of the platform is linked, a Notice says so once and the stage
runs at home.

Demonstrable end to end: a roadmap with a Windows stage, written on Linux with
the Windows device ticked at the closing Set, starts that stage on the Windows
device unasked, and the Linux device starts the stage that stands on it when it
settles. ADR-0021's *acted on by nothing* is what this ends (ADR-0029, *Placing
declared work*).
