# copy-style-guide

A writing style guide for everything Verkstead says to the human, and a review
of that copy against it. The guide lives at `docs/copy.md`, is found through a
short `CLAUDE.md`, and sets two registers: what is on screen is short and
plain, and the documents keep the voice they have. The review then rewrites
one surface at a time to match — the workbench, the settings, the wizard and
the Set sheet, the server's strings the screen shows, the desktop app — and
last the README, which names the controls the screen will have renamed, with
`docs/adoption.md` dropped as no longer relevant.

Every task after the first reads `docs/copy.md` before touching a string, and
every task leaves behaviour exactly as it was: this is copy, and the tests that
assert on copy move with it.
