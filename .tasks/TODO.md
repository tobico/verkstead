# Review

A draft whose Process is **Review** takes a pull request or a branch and wraps it
up. The Brief is scanned for the first pull request URL or `#number`, and a
**Target** field of its own in the Repo panel — reading *Pull request or branch*,
filled from the Brief while empty — takes any of the three; Start is refused
while neither names anything. Start runs today's take-up: fetch, the head cut or
fast-forwarded and a head that is ahead, diverged, checked out elsewhere or from
a fork refused by name, the head at take-up as the base commit and GitHub's base
beside it. Recording the pull request is the move into Wrapping, and the ordinary
wrap-up with its review runs from there.

A bare branch is taken up the same way with no pull request recorded and the base
picker's base kept, and one `submitting` session opens the pull request against
that base first. *Wrap up a pull request* and the list of open pull requests
behind it retire, leaving *Continue a roadmap* as Other actions' one level. Two
roles, Implementation and Review, with no *No review* row.
