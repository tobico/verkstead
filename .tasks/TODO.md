# Transfer

A Conversation moves from one device to another at a press. *Transfer to…* on
the Conversation actions menu opens a dialog with the device select and
whatever the preflight found missing on the far end; on Go the session's turn
ends as Stop ends it, the Profile's memory and login write back home, and the
work goes over — the record's slice copied under new local ids with its Rank,
the branch as a git bundle packed against what the target says it already has,
and the working changes as a binary patch beside every untracked unignored
file. Companions travel the same way. The target cuts the Worktree, applies
the patch, and Verkstead's Resume starts what ought to be running.

Every Conversation carries a cluster-wide **birth key** — the device it was
drafted on and its id there — so the Merged List draws the live copy alone, a
stale copy's URL redirects to wherever the work now is, and a transfer back
replaces that copy wholesale under its existing local id, keeping old links
working. The source keeps its copy as a tombstone, marked *transferred to* the
device that has it.
