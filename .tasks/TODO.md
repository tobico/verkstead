# Verkstead's own Question Set

Where the platform declared work wants has a device that is linked but not
ticked, or ticked but asleep, Verkstead asks rather than deciding — with a
Question Set of its own, the first it has ever authored. The Set names Verkstead
as the asker, says what wants the platform and why the device cannot be used yet,
and offers *Move to nuc-win* against *Run it here* where the device is not
permitted, and *Run it here* alone where it is permitted but asleep: the open Set
is the wait, and no answer means *wait*. A ticked device that answers before the
human does moves the work and locks the Set with a line saying so.

`verkstead transfer` on such a device becomes a request rather than a refusal:
the turn ends, the same Set goes up with *Keep it here* as its second Option,
*Move to* ticks and moves, and *Keep it here* carries the session on with a note
that the work stays. A device of the platform not linked at all stays a Notice,
and the work runs here. The decisions are ADR-0029's, *Verkstead asks with a
Question Set of its own*.
