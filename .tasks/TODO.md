# Commit summaries

Bring back what the old commit gate did well without bringing back the gate:
each code commit carries an agent-written summary — a delta diagram first,
prose after — as its message body, and the workbench shows it beside the diff.
The sweep keeps the body when it records the commit, the commit pane renders it
above the diff with the diagram drawn, and the Timeline card grows a clamped
prose snippet. The committing skills tell sessions to write it; the retired
gates Topic's diagram convention lives on there.
