# previews

A **preview** is a title and a one-line command a building session suggests
for trying its work by hand — *Build and test* over the command that runs it —
so the human never has to read the transcript to find out how. It is stored
with the conversation, keyed on its title, left and retired by the agent alone,
and run by pressing its row in a box above the Code pane's tree: a terminal
opens, the command is typed into it as the human would have typed it, and the
tab is called by the preview's title while the command runs. The Code icon on
the timeline's header takes the accent while any preview stands, so the human
can see from the timeline that there is something to try.

Settled in the grilling of 2026-10-15; the decisions are ADR-0024 and the
**Preview** entry in `CONTEXT.md`, with the **Terminal** and **Code** entries
amended. Every task reads those three before touching anything, and
`docs/copy.md` before writing a string that reaches a screen.
