# The pick on screen and the rules

With two Authors configured, the Repos pane shows each Repo's Author and lets it
be changed, and every mixing ADR-0025's grilling refused is refused by name:
repointing under live work, removing an Author a Repo points at, starting on a
Repo whose Author is gone, and a Companion Repo of another Author. Create repo's
GitHub half follows the picked Author and never falls back to the host's login,
Verkstead's own fetches present the Repo's Author's token, the Brief names the
Author beside the Repo, and the identifying fields of the Claude account in the
`.claude.json` copy are probed and either stripped or documented.

Stage 01 already landed the Open repo / Create repo picker, Create repo's first
commit and `gh repo create` as the picked Author, and a share published and
commented as the Conversation's Repo's Author. This stage builds what is left.
