# The other three roots and the memory switch

Codex, Grok Build and OpenCode sessions run in built roots by the rule stage 01
set for Claude: credentials linked, the memory store shared, a configuration
file Verkstead writes carrying only what names a model provider, and nothing
else of the human's. A built root is what a session's account *is*, whatever the
harness.

And every Agent Profile carries a **memory** switch, on by default and on for
every Profile that already exists. It says whether the account's memory store is
shared into the root, or the session starts with an empty one of its own. It
applies to every harness, Claude's included. Transcript discovery finds every
session's log either way.
