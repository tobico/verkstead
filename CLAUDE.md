# Verkstead

A single-user workbench for agentic coding: a Rust server that runs sandboxed
coding sessions, a SolidJS viewer that drives it, and a desktop app around both.

Read these before changing what they cover:

- **[CONTEXT.md](CONTEXT.md)** — the vocabulary. Read it before naming anything,
  in code or on screen, and use none of the words it lists under *Avoid*.
- **[docs/copy.md](docs/copy.md)** — how Verkstead speaks to the human. Read it
  before writing or changing any string that reaches a screen: the viewer, the
  server's refusals and notifications, the desktop app.
- **[docs/design/verkstead.md](docs/design/verkstead.md)** — what Verkstead is
  and the decisions it rests on. Read it before changing how something works.
- **[docs/development.md](docs/development.md)** — the dev shell, building, and
  running the tests. Read it before building or testing anything.
