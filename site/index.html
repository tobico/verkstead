Waiting on an agent drains your momentum, and juggling terminal tabs only splits your attention. Every agent session runs inside a sandbox with its worktree, its git directory, and nothing else of your machine. Bubblewrap on Linux, Apple's sandbox on macOS, a dedicated local account on Windows. Where no boundary is available, Verkstead refuses to run the session rather than running it bare. Let your agent run unattended, knowing it can never reach the wrong files.
